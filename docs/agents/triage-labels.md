# Triage 标签

技能用五个固定的 triage 角色说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| 角色（mattpocock/skills） | 本 tracker 的标签 | 含义                         |
| ------------------------- | ----------------- | ---------------------------- |
| `needs-triage`            | `needs-triage`    | 维护者需要判定这个 issue     |
| `needs-info`              | `needs-info`      | 等报告人补充信息             |
| `ready-for-agent`         | `ready-for-agent` | 已完成定义，可交给 AFK agent |
| `ready-for-human`         | `ready-for-human` | 需要由人来实现               |
| `wontfix`                 | `wontfix`         | 不予处理                     |

技能提到某个角色时（例如「打上 AFK-ready 的 triage 标签」），用本表对应的标签字符串。

要换成自己实际用的词汇，直接改「本 tracker 的标签」这一列。除这五个状态角色外，`/triage` 还要两个分类角色标签
`bug` 与 `enhancement`，本仓库沿用 GitHub 默认名，无需映射。
